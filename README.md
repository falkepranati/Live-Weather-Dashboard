# Live Weather Dashboard

A responsive weather dashboard built using HTML, CSS and JavaScript.

## About the Project

This application allows users to search for a city and view its weather information through an interactive dashboard.

## Features

- Search weather by city
- Display current temperature
- Weather conditions
- Humidity information
- Wind speed
- Weather icons
- Responsive dashboard design
- API integration
- Error handling for invalid city searches

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API
- Fetch API

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Search for a city to view weather information.
